Four infrastructure challenges for learning Go by building with AI.

Add one capability, run it, compare the result with the example, then continue. Each challenge gives you a concrete destination and checks along the way. You choose how to structure the code.

Pair with AI freely. Ask for explanations, predict what a change will do, and use tests to check your understanding. The aim is working software you can explain and modify. Estimates cover implementation; allow extra time for learning.

Start with the relay

Build the Ingest Relay first. The Relay Operator deploys that service, so it depends on a working relay. Gossip Glomers and Tiny TSDB are independent projects: after the relay, follow either in whichever order interests you.

01 · HTTP and concurrency

Ingest Relay

Build a service that accepts events, buffers them in a bounded queue, writes batches to disk, and drains safely on shutdown.

Bring: a Go toolchain and basic familiarity with functions and structs. Learn HTTP and concurrency as you go.

7 steps · 14–18 hours

Build the relay →

02 · Kubernetes

Relay Operator

Turn the relay into a container, then build an operator that maintains its deployment, rolls out changes, and reports status.

Bring: your working relay, a container runtime, and room to run a local Kubernetes cluster. Setup is included.

6 steps · 14–18 hours

Build the operator →

03 · Distributed systems

Gossip Glomers

Build six Go programs across Fly.io's 14 stages: messaging, unique IDs, broadcast, counters, logs, and transactions.

Bring: Go and the Java-based Maelstrom test harness. The guide includes its setup and test commands.

14 stages · 14–20 hours

Take on the distributed systems challenges →

04 · Storage

Tiny TSDB

Build a time-series database with an HTTP API, crash recovery, compressed chunks, immutable blocks, and retention.

Bring: Go and experience from the relay. No existing database code or external Go libraries are needed.

6 steps · 16–20 hours

Build the database →

Want a smaller experiment first? Try the optional five Go warm-ups on pointers, copies, channels, slices, and resource ownership. About 10–20 minutes each.
