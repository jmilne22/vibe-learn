Reading hint — identify the caller

The API server calls the webhook. The webhook returns a decision and possibly a patch; it does not call kubectl or directly store the workload.

Compare your explanation

After authentication and authorization, admission can change or reject a write. A successful mutation response carries the original request UID and an encoded JSON Patch. The API server applies that patch, finishes admission/validation, and only then persists an accepted object. Controllers subsequently create Pods, whose scheduling is a separate step.

What we change from the example

The original patch replaces the entire selector map and can discard existing constraints. Its registration matches CREATE only, uses Ignore with a 20-second timeout, and assumes a shared workload-template path. Here we preserve unrelated keys, handle UPDATE, test idempotence and diagnose Fail/Ignore. The historical image and dependency pins are not reused. JSON Patch is the mutation response format; other Kubernetes patch operations also support other formats.

Optional later discussion: Helm packaging, certificate rotation, availability, observability, and mutation versus reconciliation. A webhook changes a request; an operator repeatedly reconciles state. Building Terraform infrastructure, eBPF, an operator or a full telemetry stack is outside this eight-hour project.

"""Read-only laptop diagnostics. No packages, files, or cluster objects are changed."""
import argparse
import json
import re
import shutil
import subprocess
import sys
from pathlib import Path

TOOLS = {
    'docker': ['--version'],
    'k3d': ['version'],
    'kubectl': ['version', '--client', '-o', 'json'],
    'k9s': ['version', '--short'],
    'task': ['--version'],
    'python3': ['--version'],
    'openssl': ['version'],
    'curl': ['--version'],
}

def run(args):
    try:
        p = subprocess.run(args, capture_output=True, text=True, timeout=10, check=False)
        return p.returncode, p.stdout.strip(), p.stderr.strip()
    except (OSError, subprocess.TimeoutExpired) as exc:
        return 1, '', str(exc)


def minor(version):
    match = re.match(r'^v?(\d+)\.(\d+)', version)
    if not match:
        raise ValueError('unrecognized version: ' + version)
    return tuple(map(int, match.groups()))


def main(argv=None):
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('--ready', action='store_true', help='require a reachable, ready cluster')
    parser.add_argument('--cluster', default='admission-lab')
    args = parser.parse_args(argv)
    failures = []

    def report(level, message):
        print(f'{level}: {message}')
        if level == 'FAIL':
            failures.append(message)

    present = set()
    for name, flags in TOOLS.items():
        if not shutil.which(name):
            report('FAIL', f'{name} missing from PATH.')
            continue
        code, out, err = run([name, *flags])
        if code:
            report('FAIL', f'{name} did not respond: {(err or out)[:160]}')
        else:
            present.add(name)
            first = out.splitlines()[0] if out else '(no version output)'
            report('OK', f'{name}: {first}')
    if sys.version_info < (3, 10):
        report('FAIL', 'Use Python 3.10+; the lab uses Python 3.12.')

    if 'docker' in present:
        code, out, err = run(['docker', 'info', '--format', '{{.ServerVersion}}'])
        if code:
            report('FAIL', 'Docker daemon unavailable: ' + (err or out)[:160])
            print('HINT: Check that the Docker daemon is running and your user can access its socket.')
        else:
            report('OK', 'Docker daemon: ' + out)

    try:
        free = shutil.disk_usage(Path.cwd()).free / 1024**3
        report('WARN' if free < 8 else 'OK', f'{free:.1f} GiB disk free; allow about 8 GiB for images/cache.')
        mem = Path('/proc/meminfo')
        if mem.exists():
            available = int(re.search(r'MemAvailable:\s+(\d+)', mem.read_text()).group(1)) / 1024**2
            report('WARN' if available < 4 else 'OK', f'{available:.1f} GiB memory available; aim for 4 GiB for the lab.')
    except (OSError, AttributeError, ValueError) as exc:
        report('WARN', 'Resource estimates unavailable: ' + str(exc))

    exists = False
    if 'k3d' in present:
        code, out, err = run(['k3d', 'cluster', 'list', '-o', 'json'])
        try:
            if code:
                raise ValueError(err or out)
            exists = any(c['name'] == args.cluster for c in json.loads(out))
        except (ValueError, KeyError, TypeError) as exc:
            report('FAIL', 'Cannot inspect k3d clusters: ' + str(exc)[:160])
    if not exists:
        report('FAIL' if args.ready else 'NEXT', f'Cluster {args.cluster} not found. Follow Step 2 to create it.')
    elif 'kubectl' in present:
        k = ['kubectl', '--context', 'k3d-' + args.cluster, '--request-timeout=5s']
        code, out, err = run([*k, 'version', '-o', 'json'])
        try:
            if code:
                raise ValueError(err or out)
            versions = json.loads(out)
            client = minor(versions['clientVersion']['gitVersion'])
            server = minor(versions['serverVersion']['gitVersion'])
            if client[0] != server[0] or abs(client[1] - server[1]) > 1:
                report('FAIL', f'kubectl {client} / server {server}: select kubectl within one minor of the server.')
            else:
                report('OK', f'Client/server compatible: {client} / {server}')
        except (ValueError, KeyError, TypeError) as exc:
            report('FAIL', 'Cluster unreachable/version unreadable: ' + str(exc)[:160])
            print('HINT: export KUBECONFIG="$PWD/.kubeconfig" after following Step 2; doctor never switches context.')
        code, out, err = run([*k, 'get', 'nodes', '-o', 'json'])
        try:
            if code:
                raise ValueError(err or out)
            nodes = json.loads(out)['items']
            ready = [n for n in nodes if any(c['type'] == 'Ready' and c['status'] == 'True'
                     for c in n.get('status', {}).get('conditions', []))]
            report('OK' if len(nodes) == 2 and len(ready) == 2 else 'FAIL',
                   f'{len(ready)}/{len(nodes)} nodes Ready; lab expects two.')
        except (ValueError, KeyError, TypeError) as exc:
            report('FAIL', 'Node readiness unreadable: ' + str(exc)[:160])
    print(f'{len(failures)} blocking issue(s). ' + ('Fix these and rerun.' if failures else 'Preflight complete.'))
    return 1 if failures else 0

if __name__ == '__main__':
    raise SystemExit(main())

Step 2 — Build an image and run a Pod

Read this workflow before running commands. A Deployment describes desired state, its ReplicaSet creates Pods, the scheduler chooses a node, and that node's kubelet starts containers. A Service selects ready endpoints; it does not start containers.

  1. Build an image in the laptop Docker store.
  2. Import it into the k3d node runtimes.
  3. Create a Deployment; its controller creates a ReplicaSet and Pods.
  4. The scheduler assigns a node; the kubelet starts the image there.
  5. Observe readiness and make an HTTP request.

Use k3d for lightweight K3s in Docker and direct image import. Minikube and kind can also do this; k3d avoids introducing another setup workflow two days before an interview. Pin the node image rather than relying on k3d's installed default. k3d documentation.

Step 3 — Implement and test mutation

Keep /healthz and add POST /mutate. Separate a pure build_patch(object) function from HTTP response handling. Do not import a Kubernetes client: the API server supplies the object and applies your returned patch.

  • For apps/v1 Deployment, StatefulSet and DaemonSet CREATE/UPDATE requests, enforce lab.example.com/pool=observability at spec.template.spec.nodeSelector.
  • Preserve unrelated selectors and all other fields. Replace only the policy-owned key if conflicting. An already-compliant object returns no patch.
  • Use v1 AdmissionReview, echo request.uid, and encode the JSON operation array as UTF-8 then base64. Include patchType JSONPatch only when returning a patch.
  • Allow unsupported kinds, operations and subresources unchanged. Return HTTP 400 for a malformed envelope; FastAPI returns 422 for invalid JSON. A supported object missing the required template yields HTTP 200 with allowed:false and a useful status message. Unexpected server faults remain HTTP failures.
  • Log UID, kind, namespace, operation, result and elapsed milliseconds. Do not log the entire submitted object.

add on an existing object member replaces its value. When the map is absent, add the map first; when it exists, address the individual key. Escape ~ to ~0, then / to ~1. A returned patch is a recipe, not the full modified object.

Tests to write

Use pytest, FastAPI TestClient/httpx and jsonpatch. Check missing/empty selector maps, an unrelated selector, a conflicting owned key, all three kinds, CREATE/UPDATE, unsupported requests, malformed envelopes, explicit denial, UID equality, valid base64, dry-run, and no-op idempotence. Apply the patch to a copy and assert that the input was not changed.

Optional reference solution — main.py

Save as main.py:

import base64
import json
import logging
import time
from fastapi import Body, FastAPI, HTTPException

app = FastAPI()
log = logging.getLogger('admission')
logging.basicConfig(level=logging.INFO, format='%(message)s')
KEY = 'lab.example.com/pool'
VALUE = 'observability'
KINDS = {'Deployment', 'StatefulSet', 'DaemonSet'}


def pointer_token(key):
    return key.replace('~', '~0').replace('/', '~1')


def build_patch(obj):
    """Return operations without changing the input; unrelated selectors survive."""
    try:
        spec = obj['spec']['template']['spec']
    except (KeyError, TypeError):
        raise ValueError('expected spec.template.spec') from None
    if not isinstance(spec, dict):
        raise ValueError('expected a Pod spec object')
    selector = spec.get('nodeSelector')
    path = '/spec/template/spec/nodeSelector'
    if selector is None:
        return [{'op': 'add', 'path': path, 'value': {KEY: VALUE}}]
    if not isinstance(selector, dict) or any(not isinstance(v, str) for v in selector.values()):
        raise ValueError('nodeSelector must map strings to strings')
    if selector.get(KEY) == VALUE:
        return []
    return [{'op': 'add', 'path': path + '/' + pointer_token(KEY), 'value': VALUE}]


@app.get('/healthz')
def healthz():
    return {'status': 'ok'}


@app.post('/mutate')
def mutate(review: dict = Body(...)):
    started = time.perf_counter()
    result = 'server-error'
    fields = review.get('request')
    fields = fields if isinstance(fields, dict) else {}
    resource = fields.get('kind')
    resource = resource if isinstance(resource, dict) else {}
    try:
        req = review.get('request')
        if (review.get('apiVersion') != 'admission.k8s.io/v1'
                or review.get('kind') != 'AdmissionReview'
                or not isinstance(req, dict)
                or not isinstance(req.get('uid'), str) or not req['uid']):
            raise HTTPException(400, 'expected a v1 AdmissionReview with request.uid')
        kind = req.get('kind', {})
        if not isinstance(kind, dict):
            raise HTTPException(400, 'request.kind must be an object')
        response = {'uid': req['uid'], 'allowed': True}
        result = 'unchanged'
        supported = (kind.get('group') == 'apps' and kind.get('version') == 'v1'
                     and kind.get('kind') in KINDS
                     and req.get('operation') in {'CREATE', 'UPDATE'}
                     and not req.get('subResource'))
        if supported:
            try:
                patch = build_patch(req.get('object'))
            except ValueError as exc:
                response.update(allowed=False, status={'code': 422, 'message': str(exc)})
                result = 'denied'
            else:
                if patch:
                    response.update(patchType='JSONPatch',
                        patch=base64.b64encode(json.dumps(patch).encode()).decode('ascii'))
                    result = 'mutated'
        return {'apiVersion': 'admission.k8s.io/v1', 'kind': 'AdmissionReview', 'response': response}
    except HTTPException:
        result = 'malformed'
        raise
    except Exception:
        result = 'server-error'
        raise
    finally:
        log.info(json.dumps({'uid': fields.get('uid'), 'kind': resource.get('kind'),
                 'namespace': fields.get('namespace'), 'operation': fields.get('operation'),
                 'result': result, 'elapsed_ms': round((time.perf_counter()-started)*1000, 3)}))
Optional reference tests — test_main.py

Save as test_main.py:

import base64
import copy
import json
import pytest
import jsonpatch
from fastapi.testclient import TestClient
from main import app, build_patch, pointer_token, KEY, VALUE

client = TestClient(app)

def workload(selector=None):
    spec = {'containers': [{'name': 'app', 'image': 'admission-lab:v1'}]}
    if selector is not None:
        spec['nodeSelector'] = selector
    return {'spec': {'template': {'spec': spec}}}

def review(obj, kind='Deployment', operation='CREATE'):
    return {'apiVersion': 'admission.k8s.io/v1', 'kind': 'AdmissionReview',
            'request': {'uid': 'request-123', 'namespace': 'admission-demo',
                        'kind': {'group': 'apps', 'version': 'v1', 'kind': kind},
                        'operation': operation, 'object': obj}}

@pytest.mark.parametrize('selector', [None, {}, {'kubernetes.io/os': 'linux'},
    {KEY: 'wrong', 'kubernetes.io/os': 'linux'}, {KEY: VALUE}])
def test_patch_preserves_and_converges(selector):
    original = workload(selector)
    before = copy.deepcopy(original)
    changed = jsonpatch.apply_patch(original, build_patch(original), in_place=False)
    assert original == before
    selectors = changed['spec']['template']['spec']['nodeSelector']
    assert selectors == {**(selector or {}), KEY: VALUE}
    assert build_patch(changed) == []
    assert changed['spec']['template']['spec']['containers'] == before['spec']['template']['spec']['containers']

def test_pointer():
    assert pointer_token('a~/b') == 'a~0~1b'

@pytest.mark.parametrize('kind', ['Deployment', 'StatefulSet', 'DaemonSet'])
@pytest.mark.parametrize('operation', ['CREATE', 'UPDATE'])
def test_protocol(kind, operation):
    obj = workload({'kubernetes.io/os': 'linux'})
    r = client.post('/mutate', json=review(obj, kind, operation))
    assert r.status_code == 200
    body = r.json()
    assert body['apiVersion'] == 'admission.k8s.io/v1'
    assert body['kind'] == 'AdmissionReview'
    response = body['response']
    assert response['uid'] == 'request-123' and response['allowed'] is True
    assert response['patchType'] == 'JSONPatch'
    patch = json.loads(base64.b64decode(response['patch'], validate=True))
    assert jsonpatch.apply_patch(obj, patch)['spec']['template']['spec']['nodeSelector'][KEY] == VALUE

@pytest.mark.parametrize('kind,operation', [('Pod', 'CREATE'), ('Deployment', 'DELETE')])
def test_unsupported(kind, operation):
    response = client.post('/mutate', json=review(None, kind, operation)).json()['response']
    assert response == {'uid': 'request-123', 'allowed': True}

def test_no_patch_and_dry_run():
    r = review(workload({KEY: VALUE}))
    r['request']['dryRun'] = True
    assert client.post('/mutate', json=r).json()['response'] == {'uid': 'request-123', 'allowed': True}
    r = review(workload())
    r['request']['dryRun'] = True
    assert 'patch' in client.post('/mutate', json=r).json()['response']

def test_malformed_envelope_and_explicit_denial():
    assert client.post('/mutate', json={}).status_code == 400
    assert client.post('/mutate', content='not json', headers={'Content-Type': 'application/json'}).status_code == 422
    r = client.post('/mutate', json=review({'spec': {}}))
    assert r.status_code == 200
    assert r.json()['response']['allowed'] is False
    assert 'spec.template.spec' in r.json()['response']['status']['message']

def test_health():
    assert client.get('/healthz').json() == {'status': 'ok'}


def test_server_failure_is_not_an_admission_denial(monkeypatch, caplog):
    import main
    def broken(_):
        raise RuntimeError('simulated server fault')
    monkeypatch.setattr(main, 'build_patch', broken)
    with caplog.at_level('INFO', logger='admission'):
        response = TestClient(app, raise_server_exceptions=False).post('/mutate', json=review(workload()))
    assert response.status_code == 500
    record = json.loads(caplog.records[-1].message)
    assert record['uid'] == 'request-123'
    assert record['result'] == 'server-error'
    assert record['elapsed_ms'] >= 0


def test_malformed_envelope_is_logged(caplog):
    with caplog.at_level('INFO', logger='admission'):
        assert client.post('/mutate', json={}).status_code == 400
    record = json.loads(caplog.records[-1].message)
    assert record['uid'] is None and record['result'] == 'malformed'

Architecture — what runs where

This map shows the complete lab. Boxes identify components and their boundaries; the green connection is the webhook request and response, while the left-hand path is workload creation and placement.

  1. Laptop → API server. kubectl submits objects and k9s inspects API state. Docker builds the image; k3d imports it into both node runtimes.
  2. API server ↔ webhook. MutatingWebhookConfiguration supplies matching rules, namespace selection, the Service reference and CA bundle. The placement-webhook Service routes 443 to Uvicorn on 8443. The placement-tls Secret supplies the certificate and key. The webhook returns a decision and optional patch to the API server.
  3. Accepted state → controllers. After mutation and validation, the API server persists the workload. Controllers create Pods from its template; the scheduler assigns those Pods to eligible nodes.
  4. Agent → running containers. The agent's kubelet uses its imported image to start the selected application Pods. The pool label satisfies the selector enforced by the webhook.

admission-system is excluded from mutation. Namespaces are logical groupings, not separate machines: the webhook has no node pinning, while admission-demo workload templates acquire the observability selector.

Follow one admission request

  1. The API server authenticates and authorizes a write.
  2. Matching admission rules call the HTTPS webhook with an AdmissionReview.
  3. The API server applies the returned patch and completes validation.
  4. Only an accepted write is persisted. Server-side dry-run traverses admission without this persistence step.
  5. Controllers and the scheduler act afterward. New Pods have their own admission; this lab registers workload-template mutation only.

The webhook's namespace must stay outside its own policy. A TLS probe can be healthy while the API server rejects the certificate; Kubernetes HTTPS probes do not establish this CA/SAN trust for you. Registration should be the last deployment step.

Write the configuration

Create a locally signed server certificate for placement-webhook.admission-system.svc. Mount it from placement-tls. Serve HTTPS on 8443, expose Service port 443, select only namespaces labeled lab.example.com/admission=enabled, and register apps/v1 deployments/statefulsets/daemonsets CREATE and UPDATE. Use v1 reviews, sideEffects None, timeoutSeconds 3 and failurePolicy Fail.

Hint — distinguish the two certificates

The API server needs the CA certificate in caBundle. The serving Pod needs the server certificate and its private key. The CA private key is only used locally for signing. The server certificate SAN must match the Service identity.

Supplied certificate helper — certificates.sh

Save as certificates.sh:

#!/usr/bin/env bash
set -euo pipefail
mkdir -p certs
umask 077
openssl req -x509 -newkey rsa:2048 -nodes -days 7 \
  -keyout certs/ca.key -out certs/ca.crt -subj '/CN=Admission Lab CA' \
  -addext 'basicConstraints=critical,CA:TRUE' \
  -addext 'keyUsage=critical,keyCertSign,cRLSign'
openssl req -new -newkey rsa:2048 -nodes \
  -keyout certs/tls.key -out certs/tls.csr -subj '/CN=placement-webhook'
cat > certs/server.ext <<'EXT'
basicConstraints=critical,CA:FALSE
keyUsage=critical,digitalSignature,keyEncipherment
extendedKeyUsage=serverAuth
subjectAltName=DNS:placement-webhook.admission-system.svc
EXT
openssl x509 -req -in certs/tls.csr -CA certs/ca.crt -CAkey certs/ca.key \
  -CAcreateserial -out certs/tls.crt -days 7 -sha256 -extfile certs/server.ext
openssl verify -CAfile certs/ca.crt -verify_hostname placement-webhook.admission-system.svc certs/tls.crt

Optional registration generator — register.py

"""Generate webhook.json after certificates.sh; apply only when serving is ready."""
import base64
import json
from pathlib import Path
config = {
    'apiVersion': 'admissionregistration.k8s.io/v1',
    'kind': 'MutatingWebhookConfiguration',
    'metadata': {'name': 'placement-webhook'},
    'webhooks': [{
        'name': 'placement.lab.example.com',
        'admissionReviewVersions': ['v1'], 'sideEffects': 'None',
        'failurePolicy': 'Fail', 'timeoutSeconds': 3,
        'namespaceSelector': {'matchLabels': {'lab.example.com/admission': 'enabled'}},
        'rules': [{'operations': ['CREATE', 'UPDATE'], 'apiGroups': ['apps'],
                   'apiVersions': ['v1'], 'resources': ['deployments', 'statefulsets', 'daemonsets'],
                   'scope': 'Namespaced'}],
        'clientConfig': {
            'service': {'namespace': 'admission-system', 'name': 'placement-webhook',
                        'path': '/mutate', 'port': 443},
            'caBundle': base64.b64encode(Path('certs/ca.crt').read_bytes()).decode('ascii')
        }
    }]
}
Path('webhook.json').write_text(json.dumps(config, indent=2) + '\n')

Review answer — idempotence is broader than reinvocation

Even with default reinvocationPolicy Never, users can submit an already-mutated object and UPDATE calls can repeat. The pure patch tests establish the no-op property. An admission webhook cannot guarantee the final policy against all later mutations; production enforcement may also require validation. See webhook good practices.

3 · Wrong CA trust

Hint — certificate identity versus trust

Expect a certificate verification error, not an application admission log. A wrong SAN causes a hostname error; a wrong CA causes an issuer/trust error. Both happen before the HTTP handler.

Repair TLS trust
kubectl apply -f webhook.json
openssl verify -CAfile certs/ca.crt -verify_hostname placement-webhook.admission-system.svc certs/tls.crt
kubectl -n admission-demo create deployment tls-fault --image=admission-lab:v1

Allow registration propagation and retry if needed. Never use curl -k as evidence that API-server trust works.

4 · Unavailable webhook: Fail versus Ignore

kubectl -n admission-system scale deployment placement-webhook --replicas=0
kubectl -n admission-system wait --for=delete pod -l app=placement-webhook --timeout=60s
kubectl -n admission-demo create deployment fail-closed --image=admission-lab:v1
# Expect failure. Now change the failure policy.
kubectl patch mutatingwebhookconfiguration placement-webhook --type=json   -p '[{"op":"replace","path":"/webhooks/0/failurePolicy","value":"Ignore"}]'
kubectl -n admission-demo create deployment fail-open --image=admission-lab:v1
kubectl -n admission-demo get deployment fail-open -o jsonpath='{.spec.template.spec.nodeSelector}'
Hint — Ignore is not an override for denial

Ignore skips webhook call failures. It does not override a valid allowed:false response. Fail-open should exist without the injected selector; retry after configuration propagation if initially rejected.

Restore serving and policy
kubectl -n admission-system scale deployment placement-webhook --replicas=1
kubectl -n admission-system rollout status deployment/placement-webhook --timeout=90s
kubectl apply -f webhook.json
kubectl -n admission-demo delete deployment fail-open --ignore-not-found

Discuss availability versus enforcement. A production mutation default may fail open and rely on separate validation; the lab uses Fail to expose wiring errors.
